# Random Task Generator - Генератор случайных задач

## Информация об авторе 
**Имя и Фамилия:** Никита Жигунов 
**Дата создания:** Май 2026


## Описание программы 

Random Task Generator - это графическое приложение на Python для генерации случайных задач. Приложение помогает пользователям получать случайные задачи из различных категорий (учёба, спорт, работа), отслеживать историю выполненных задач и управлять списком доступных задач.

### Возможности
- ✅ Генерация случайных задач из списка
- ✅ Фильтрация задач по типам (учёба, спорт, работа)
- ✅ Отображение истории сгенерированных задач
- ✅ Добавление новых задач с указанием типа
- ✅ Автоматическое сохранение задач и истории в JSON
- ✅ Проверка корректности ввода (не пустая строка)
- ✅ Красивый и интуитивно понятный интерфейс

## Инструкция по запуску

### Требования
- Python 3.6 или выше
- Tkinter (обычно установлен по умолчанию)

## Примеры использования 

### Генерация случайной задачи
1. Запустите приложение 
2. Нажмите кнопку "Сгенерировать задачу"
3. Появится случайная задача напрмер: "Сделать зарядку 15 минут[спорт]
4. Задача автоматически добавится в историю с временной меткой
